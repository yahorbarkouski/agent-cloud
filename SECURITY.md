# Report a vulnerability

Use [GitHub's private vulnerability report](https://github.com/yahorbarkouski/agent-cloud/security/advisories/new). Include the affected source revision, the smallest reproduction and the observed authorization, data or spending impact. Remove credentials and customer data from attachments. The maintainers can arrange a private reproduction when necessary.

The current release is a developer preview. Report issues against the latest preview or current source; there is no long-term support branch yet. Read the verification limits in the README and subsystem documentation before operating a customer cloud.

Release signatures establish where an archive was built. Verify the repository, release tag and source revision using [the installation guide](docs/cli-install.md). Operator credentials, backup keys and application secrets do not belong in the source repository or release artifacts.
